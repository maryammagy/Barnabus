# Engineering Defect Ledger

Status meaning: **resolved** requires an implemented control and focused passing evidence; **contained** means the source condition remains but the pipeline detects, isolates, and reports it without silently corrupting published output; **open** means implementation, evidence, or sealed-scale validation is incomplete. The evidence below refers to the 28-test local suite and artifact set `505a3cf4959488781a214c483e6159fe31482e92a7490532b370756dc1cced0e` unless stated otherwise.

| Defect | Evidence and treatment | Status | Justification | Difficulty |
|---|---|---|---|---|
| Local workload is far smaller than the evaluation workload | DuckDB performs projected out-of-core scans with an 8-thread/12 GB cap and step telemetry. The clean local run processed 1,921,253 rows in 114.864 seconds with 4,560,781,312 bytes peak RSS. | open | The local workload and distribution cannot prove the approximately 400M-row, 16 GB, 8-core, under-40-minute gate. The generated linear projection is explicitly unvalidated. | High |
| Ingestion partitions continue beyond the study window | `partition_characterization.parquet` inventories all 16 partitions and separately counts in-window late arrivals and post-study event time; `test_beyond_window_partition_is_characterized_not_deleted` passes. | resolved | The pipeline does not filter by filename and publishes the source-local and UTC study status. | Medium |
| Retry duplicates change transport metadata | The semantic key excludes event ID, ingestion time, and source transport fields; deterministic earliest-ingest survival and retry counts are published. `test_semantic_dedup_ignores_retry_delivery_metadata` passes. | resolved | The local run reduces 1,921,088 accepted rows to 1,892,668 semantic events without using `event_id` as business identity. | High |
| `event_id` can be malformed, duplicated, or reused | Malformed IDs are fatal with a retained diagnostic cache; normalized `event_id` uniqueness is asserted. `test_malformed_or_unmatched_key_fails_with_diagnostic_cache[malformed-event-id]` passes. | contained | Duplicate/reused IDs fail loudly through the uniqueness contract, but an explicit incompatible-reuse fixture is not yet present. | Medium |

All three `test_timeutils.py` tests pass over 2025-11-02 and 2026-03-08. | contained | Correctness is tested, but `America/Chicago` for `hisA` and UTC for device are inferred configuration, not supplied authority. | High |
| `service_code` / `svc_code` schema evolution and defaults | The current code wins only when meaningful; otherwise the legacy code is used and the `UNKNOWN` backfill is labeled. Identifier, cardinality, and unmatched-key tests pass. | resolved | Normalization and join behavior are executable rather than implicit. | Medium |
| Lookup duplication multiplies facts | Snapshot rows are aggregated to one normalized case before reconciliation; generic many-to-one contracts fail on duplicate lookup keys. `test_conflicting_snapshot_rows_aggregate_without_multiplying_reconciliation` passes. | resolved | Snapshot conflicts remain one reconciliation row with conflict counts. | High |

| Undocumented telemetry corrupts workflow state | Five observed operational event types are allowlisted, retained in canonical history, and excluded from workflow state. `test_operational_event_is_retained_but_excluded_from_workflow_state` passes. | resolved | Telemetry cannot become a workflow transition silently. | Medium |
| Raw source can be modified accidentally | The source root is external; runtime and output roots must be distinct and outside it; Compose mounts `/data` read-only; raw patterns are ignored by Git. | resolved | Both configuration checks and the documented container path prevent normal production writes to source data. | Low |
| A notebook becomes part of reproduction | Production entry points are Python modules/CLI and Compose commands; no notebook dependency or `.ipynb` file is present. | resolved | All generated engineering numbers originate in executable scripts and manifests. | Low |
| Volatile metadata breaks byte identity | Operational time/RSS telemetry is stored under ignored `work/`; deterministic artifacts omit timestamps and personal paths. Full/incremental byte-identity tests and local hash verification pass. | resolved | The same inputs/config/code/environment yield the same artifact set. | Medium |
| Source text contains instructions or sensitive-looking content | The engineering path projects only typed event/snapshot/dimension fields and never interprets text as instructions. | Hidden sealed mutation behavior is underspecified | Mechanism-based invariants and arbitrary-backfill/replay tests avoid claim-specific hard-coding. | open | Local fixtures cannot prove behavior against an undisclosed sealed generator or mutation contract. | High |

No `resolved` label substitutes for the sealed hard-gate run. The open scale and hidden-generator items remain explicit release risks.

## Scientific supplement defects

Evidence below refers to the 56-test local suite and scientific result `3741598adc31cfdc61c050be5b97e2de93154823e6d859298456a73fb2d4125a`. “Resolved” here means the candidate pipeline handles the local condition; it does not manufacture missing scientific authority.

| Defect | Evidence and treatment | Status | Justification | Difficulty |
|---|---|---|---|---|
| Reviewer labels have no authorized adjudication | The supplied adjudication field has zero completed entries; candidate-created agreement classes are separately labeled, and `adjudication_protocol.csv` defines a future blinded third-clinician process with an UNRESOLVED option. | open | Agreement can be measured, but no single ground-truth label or accuracy claim can be created by the candidate. | High |
| LLM judge is evaluated only in the same-family condition | Reviewer-specific sensitivity, specificity, average precision, calibration, and binary weighted kappa use service-cluster intervals; `judge_family_dependence.csv` records zero different-family rows and the autonomy/triage gates fail. | open | Shared-family error dependence cannot be quantified or used as independent validation without new scores. | High |
| Label/model/uplift inputs can contain duplicate keys, invalid enums, or out-of-range scores | Normalized unique-key, enum, finite/range, one-to-one coverage, and row-flow checks run before evaluation; focused negative unit tests cover range and grain failure. | resolved | Bad typed inputs fail loudly, while unmatched/outcome-unobserved rows remain counted in flow tables. | Medium |
| Recommendation-model target and feature lineage are absent | Every performance, calibration, decision-curve, consequence, and subgroup row is labeled `invalidated_sensitivity_only`; all 38,135 evaluated proxy rows fail the feature-lineage authority gate. | contained | The source defect remains, but no affected number is presented as clinical performance or deployment evidence. | High |
| The actually used threshold could be hidden by outcome filtering | All 40,000 supplied score rows are audited before outcome alignment; the local file has one threshold. Multiple thresholds fail loudly instead of being silently collapsed. | resolved | The local operating threshold is reproducible, including exclusions, though a future multi-threshold file requires an explicit version-stratified extension. | Medium |
| Reliability intervals use patient-level independence | Reliability bins are fixed once and their outcome-rate intervals use deterministic service-cluster resampling based on cluster/bin sufficient statistics. | resolved | The published reliability intervals never use patient-IID Wilson uncertainty. | Medium |
| Sparse subgroups invite false precision | Inferential subgroup bounds are suppressed below five services or 20 episodes; service-only groups remain descriptive with counts and reasons. | resolved | A one-service subgroup cannot emit an inferential interval. | Low |
| Uplift AUC is substituted for causal targeting performance | The supplied AUC is labeled `unreproduced` and invalid; the top-ranked slice visibly fails overlap; causal Qini, AUUC, uplift calibration, and policy value are not estimated. | contained | Descriptive targeted/not-targeted associations remain available without being renamed causal uplift. New randomized/logged assignment data are still required. | High |
| Interference units are not operationally certified | The pre-switch clinician-plus-ward graph yields eight provisional components, four per site, and all assignment/power outputs carry provisional labels. | open | Component independence, crossover, and simultaneous activation must be certified prospectively. | High |
| Power simulation can mishandle wash-in, correlation, and Monte Carlo error | Component-specific wash-in cells are excluded; simulations include persistent component shifts, AR(1) variation, seasonality, policy/time scenarios, common random numbers, empirical null calibration, Monte Carlo intervals, and a lower-bound MDE rule. | contained | The simulator is fit for provisional planning, but its proxy baseline and working-correlation parameters are not an authorized clinical design basis. | High |
| Sequential operating characteristics are not simulated | Benefit, nonbinding futility, and harm boundaries are specified with directions, information fractions, actions, and DSMB authority, while tables/report explicitly label fixed-final power only. | open | A confirmatory protocol still needs simulation of the complete sequential design after endpoint and component certification. | High |
| Supplied monitoring alerts have no reproducible rule or version history | The supplied 29 flags are retained; the strictly-prior candidate replay produces zero alerts and labels all 29 disagreements as non-reproduction, not errors in the supplied flags. | open | One annual cycle and no as-of timestamps cannot validate seasonality, endpoint maturity, or the supplied rule. | High |
| Monitoring can leak future rows or budget away hard stops | Candidate baselines use only earlier weeks; statistical warnings require shrinkage, denominator gates, BY correction, and persistence; contract, authorization, provenance, harm, and scale stops have no suppression or alert cap. | resolved | The executable replay and catalog now agree with the stated false-alert and stop-authority rules. | Medium |
| Scientific tables or reported numbers lack provenance | All 36 tables have enforced declared grains; 15,421 numeric cells have IDs; 45 artifacts verify; the manifest hashes every direct input, the locked parent, configuration, and all imported producing modules. | resolved | The immediate rerun returned the same result ID and verified hashes. | High |
| Scientific container and sealed-scale execution are unproved | Compose validates and the source bind is read-only, but Docker Desktop’s Linux engine was unavailable and no sealed workload was run. | open | Local Python 3.12 execution cannot prove the container or approximately 400M-row gate. | High |
| Long Windows temporary roots can exceed path limits | A deliberately relocated pytest temp root under the workspace caused DuckDB staging failures; the normal shorter system temp root passed all 56 tests. | open | Production should use a short work/output mount on Windows or run in the intended Linux container; arbitrary deep Windows roots remain unsafe. | Medium |
| Windows atomic directory publication can fail transiently | One generated pipeline publication returned `WinError 5`; no scientific result was published, and an unchanged retry completed with verified hashes.
